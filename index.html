Standard Operating Procedures — How This System Works
🆕 New Client Onboarding (Steps)
Step 1 — Send welcome email + intake form within 24 hrs
Step 2 — Add client to roster with full details
Step 3 — Set up shared Google Drive folder structure
Step 4 — Create recurring tasks in task log
Step 5 — Schedule 7-day check-in follow-up
Step 6 — Move card from Onboarding → Active in pipeline
📋 Weekly VA Routine
Mon — Review all deadlines for the week, send check-ins
Tue–Thu — Execute tasks by priority (High → Medium → Low)
Fri — Update task log statuses, flag anything at risk
Fri EOD — Send weekly summary to each active client
Daily — Check follow-up tab for any overdue items
🚦 Task Priority Rules
High — Deadline within 2 days OR client-flagged urgent
Medium — Deadline 3–7 days, standard deliverable
Low — Deadline 8+ days OR nice-to-have task
Always complete High tasks before moving to Medium. Communicate proactively if a High task will be delayed.
🔚 Client Offboarding (Steps)
Step 1 — Notify client of final deliverables 1 week before end
Step 2 — Complete all open tasks; close or hand over pending items
Step 3 — Send final report + file summary
Step 4 — Archive client folder; move card to Wrap-Up
Step 5 — Send thank-you + request testimonial
Step 6 — Send final invoice; update roster status to Inactive

Standard Operating Procedures — VA Workflow SOPs
📅
Daily Email & Calendar Management
  1. Check all client inboxes — 8:00 AM PHT
  2. Sort into: Urgent / Action / FYI / Archive
  3. Draft replies for Urgent items → send within 1 hour
  4. Review calendar — flag conflicts or gaps
  5. Confirm next-day appointments 24 hrs in advance
  6. Log all actions in the Task Log with timestamps
⏱ Est. daily time: 45–60 mins
🔄
New Task Intake Process
  1. Receive task via agreed channel (email / Slack / WhatsApp)
  2. Log in Master Task Log within 30 minutes of receipt
  3. Assign: Client · Type · Priority · Deadline · Est. Hours
  4. Acknowledge receipt to client with ETA
  5. Add to Kanban board in "To Do" column
  6. Begin work or schedule in calendar block
⏱ Est. intake time: 10–15 mins per task
📊
Weekly Client Report SOP
  1. Every Friday — pull completed tasks from log
  2. Summarize by client: tasks done, hours logged, pending
  3. Note any blockers or items waiting on client approval
  4. Format in agreed template (email or Google Doc)
  5. Send by 4:00 PM PHT — copy to shared drive
  6. Log send date in Follow-Up Tracker, set 3-day reminder
⏱ Est. weekly time: 30–45 mins per client
🚨
Urgent / Overdue Task Protocol
  1. Identify overdue or same-day urgent tasks at 8 AM check
  2. Flag red in Kanban — move to top of In Progress column
  3. Notify client immediately with revised ETA
  4. Pause all Low-priority work until urgent item is resolved
  5. Complete & deliver — confirm receipt with client
  6. Document in Task Log: reason for delay + resolution
⏱ Response target: within 1 hour of identification
